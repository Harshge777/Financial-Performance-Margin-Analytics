# Financial Performance & Margin Analytics

## Project Overview
This project analyzes financial transaction data to evaluate revenue, costs, profitability, profit margins, customer performance, product performance, and shipping duration.

The objective is to identify important business trends and generate actionable insights using Python, SQL, and Power BI.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- MySQL
- Power BI
- Jupyter Notebook
- Microsoft Excel

## Dataset
- 6,000 transaction records
- Includes order dates, customers, products, categories, quantities, revenue, costs, margins, and shipping dates.
- The dataset is synthetic and created for analytical and portfolio purposes.

## Key Performance Indicators
| Metric | Value |
|---|---:|
| Total Revenue | 3,480,101.59 |
| Total Cost | 2,447,444.00 |
| Total Profit | 1,032,657.59 |
| Profit Margin | 29.67% |
| Total Records | 6,000 |
| Average Shipping Duration | 3.23 days |

## Project Workflow
1. Data loading and inspection
2. Data cleaning and validation using Python
3. Exploratory Data Analysis (EDA)
4. SQL-based business analysis
5. Power BI dashboard development
6. Business insights and recommendations

## Key Business Insights
- Paper & Tissue generated the highest revenue but had the lowest profit margin (23.85%).
- Cleaning Supplies generated the highest total profit.
- Breakroom Supplies had the highest profit margin (40.65%).
- 66.90% of orders had a shipping duration of one day.
- Average shipping duration was approximately 3.23 days.
